# Huf v1.0.0-beta.10

Beta 10 is a fix release for Event Aliases, which shipped in beta.9. Beta.9 had two defects, described below. Both are fixed here.

## Fixes

### Event Alias hook could recurse before migrate
- **Defect in beta.9:** on a site that upgraded but had not yet run `bench migrate`, the `Event Alias` table did not exist. The Event Alias hook failed on every document event, logging the error created another document event, and the hook ran again until the stack or the database connection gave out. The first migrate after upgrading was affected.
- **Fixed:** the hook does nothing while migrate is running and returns an empty alias map when the Event Alias tables do not exist yet. It can no longer call itself, and it never raises out of a document event.
- **Legitimate events are no longer skipped:** the hook ignores only Event Alias, Event Alias Source and Error Log. Aliases on other doctypes, including Communication and Comment, keep working.

### Duplicate-event protection did not work
- **Defect in beta.9:** the dedupe check always reported a new event, so repeated saves could fire an automation twice.
- **Fixed:** the dedupe check now reads the shared cache correctly, so duplicate events are dropped.

## Upgrade

```bash
bench --site <site> migrate
```

Sites already on beta.9 that have migrated need no other action.
