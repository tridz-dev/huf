# Huf v1.0.0-beta.9

Beta 9 adds Event Aliases, so automations can react to business events instead of raw document events, and refreshes the New agent card.

## Highlights

### Event Aliases
- **Business names for document events:** an Event Alias maps a document event, for example a Sales Invoice being submitted, to a named event such as `shop.customer_purchase`, with an optional condition and payload.
- **Uses the existing App Event trigger:** the named event fires the App Event automation trigger, so there is no new trigger type.
- **Safe by design:** an alias fires once, after commit. A rollback fires nothing, and repeated saves are de-duplicated. Errors are logged and counted and never fail the save.
- **No cost when unused:** doctypes without aliases cost one cached lookup and no queries. The cache clears when an alias is saved or deleted.
- **Ship aliases with an app:** put them in a `huf/event_aliases` folder and they load with the rest of the app's seed data.
- **API:** new methods to list, get and emit event aliases.
- **Fix:** saved App Event triggers now show their event in the trigger list.

### Business event picker
- **Trigger editor:** choose the event from a list instead of typing the app and event names.
- **States:** shows a loading placeholder, an alert with typed-field fallback if the list fails to load, and a hint linking to Desk when no business events exist.
- **Phased-out events:** a saved event that is phased out, or no longer in the list, shows a warning. When a replacement exists there is a **Switch to** button. Nothing is rewritten automatically.
- **Draft automations:** a note explains that App Event triggers do not fire until the automation is activated.
- **After create:** creating an automation now opens it instead of the agent page.

### Agent create card
- **Instructions first:** the New agent card leads with free-text instructions and an example-rich placeholder.
- **Examples:** four featured example chips and a searchable gallery of 15 examples across support, sales, HR, finance, operations, data entry, WhatsApp and web chat, knowledge, automation and research. A picked example stays visible as a chip.
- **Accessibility:** the Name and Instructions labels are now linked to their inputs.

### Documentation
- Beta.8 screenshots of the redesigned Agent form and Tables.

## Upgrade

```bash
bench --site <site> migrate
```

The migrate adds the `Event Alias` and `Event Alias Source` doctypes.
