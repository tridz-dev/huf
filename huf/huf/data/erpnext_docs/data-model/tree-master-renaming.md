# Tree Master Renaming

ERPNext includes numerous documents organized as tree structures. For instructions on managing these hierarchies, see the tree structure masters guide.

## Steps for Renaming Tree Structure Masters

To rename a master document in a tree structure (using an Account as an example):

**Step 1: Access the Tree View**
Navigate to the tree view of your document.

**Step 2: Locate and Select the Node**
Find the specific node you want to rename. When clicked, a rename option becomes available.

![Tree Master Renaming](/files/using-tree-renaming-1.png)

**Step 3: Rename the Document**
Selecting rename triggers a pop-up dialog where you can enter the new name for your document.

![Tree Master Renaming](/files/using-tree-renaming-2.gif)
