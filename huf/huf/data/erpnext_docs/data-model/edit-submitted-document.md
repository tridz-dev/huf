# Edit Submitted Document

To modify a submitted document, you must first cancel it. The process involves three key steps, and you'll need appropriate permissions for cancellation and editing.

## Step 1: Cancel Submitted Document

Locate the Cancel button in the upper right corner of the submitted document interface.

## Step 2: Amend the document

Once you cancel the submitted document, an Amend button becomes available.

## Step 3: Save and Submit the document

Clicking the Amend button reopens the document for editing. Make your necessary changes, then save and resubmit.

## Important Note

If your document has linked dependencies with other records, you must cancel those dependent documents first. For example, if a Sales Order has associated Delivery Notes and Sales Invoices that you need to amend, cancel those related documents before cancelling the parent Sales Order. Only then can you amend, re-save, and re-submit the Sales Order.
