# Signature Field

Electronic signature functionality in ERPNext can be implemented through the Signature field type. This field type enables users to "write a signature in a block, just like the signature on a paper."

## Steps to Create an Electronic Signature

1. Open the DocType and navigate to Customize Form
2. In the Form view or Fields table, add a new field named Signature and set the Field Type to **Signature**
3. Click Update
4. Refresh the page and input your signature

The documentation includes screenshots demonstrating the field configuration interface and the resulting signature input interface in the form.
