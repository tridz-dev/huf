# Duplicate Records

**The 'Duplicate' feature enables users to copy all values from an existing document into a newly created document.**

## Scenario

Consider a situation where a customer reorders items from an electronics supplier. When the new Sales Order contains identical information as the original order, the supplier can access the original document and select 'Duplicate' from the menu options. This action transfers all field values from the source document into the new Sales Order. Any necessary modifications can be applied afterward.

## How to Create a Duplicate Document

To generate a duplicate, navigate to the original document and select 'Duplicate' from the dropdown menu.
