# Website Components

ERPNext provides various website components designed to meet different business needs, including web forms, sidebars, and slideshows for webpage creation.

## Overview

"Web forms in ERPNext allow businesses to gather customer data efficiently through customisable forms" embedded on web pages. Sidebars offer space to display navigation links, social feeds, or marketing content, enhancing user engagement. Slideshows present images and promotions in visually compelling ways that capture visitor attention and communicate important information.

These tools enable organizations to construct interactive, user-friendly digital experiences that boost engagement and support marketing objectives.
