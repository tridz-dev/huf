# 2 Step 301 Redirect in your ERPNext Website

## What is 301 Redirect?

A **301 Redirect** serves an important purpose in web management. According to the documentation, "A 301 Redirect is used to make sure that search engines and users are sent to the correct page." This status code indicates that webpage content has been permanently relocated. When implemented, visitors will observe the updated URL in their browser, as the new page replaces the old one.

## 2 Step 301 Redirects with ERPNext

**Step 1:** Navigate to Website Settings using the awesome bar (Global Search Bar) and locate the "Redirects" section to expand it.

**Step 2:** Input the previous URL in the Source field and the new URL in the Target field, then save your changes.
