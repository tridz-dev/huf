# Website Banner Resizing

Each ERPNext account website is automatically generated. On a website, the logo is established based on the logo image selected during the Setup Wizard. You have the ability to modify or adjust logo properties for your company through the Website Settings.

**Navigation path:** `Explore > Website > Website Settings`

For detailed instructions on uploading a Website Banner and adjusting its dimensions, consult the guidance provided below.
