# Disable Signup on ERPNext Website

ERPNext includes a portal feature that enables external parties like customers and suppliers to register, create new orders, and monitor order status updates.

To prevent new customer and supplier registrations, follow these steps:

## Steps

1. Navigate to **Website > Setup > Website Settings**

2. Scroll down to the "More Information" section on the Website Settings page.

3. Check the field labeled "Disable Signup".

4. Save your Website Settings changes.

By enabling this setting, you will prevent new users from accessing the signup functionality on your ERPNext portal login page.
