# Web Page Builder

## Overview

The Web Page Builder feature, introduced in Version 13, enables users to "quickly create web pages from pre-configured web templates."

## Creating a Page Using Page Builder

The process involves these steps:

1. Create a Web Page following standard procedures
2. Enable full width by checking the "Full Width" checkbox
3. Set Content Type to **Page Builder**
4. Add a row in the Page Building Blocks Table
5. Choose a Web Template
6. Click **Edit Values** button
7. Input values in the dialog and submit
8. Save the page
9. Check **Published** to make the page live

After creation, view your page by selecting **See on Website** in the sidebar.

## Adding Sections

Additional sections can be incorporated by creating more rows in the Page Building Blocks table. The framework provides numerous Web Templates for diverse page designs.

## Section Configuration Options

Expanding a row in the Page Building Blocks table reveals these customization settings:

- **Add Container**: Centers the template in a constrained box
- **Add Space on Top**: Adds spacing above the section
- **Add Space on Bottom**: Adds spacing below the section
- **Add Gray Background**: Applies gray background color
- **Hide Block**: Conceals the section
- **CSS Class**: Allows custom CSS styling via the Style section
