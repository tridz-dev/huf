# Stock Value and Account Value Comparison Report

This report enables users to identify discrepancies between the stock account and stock balance report. According to the documentation, "At the end of the financial year, every organization has to match its closing stock balance with the closing stock account."

## Purpose

The report serves to clarify why stock values might not align. When reconciliation issues arise, users can consult this report to pinpoint problematic transactions and subsequently create the necessary adjustment entries.

## Access

To locate this report, navigate through:

> Home > Stock > Other Reports > Stock and Account Value Comparison
