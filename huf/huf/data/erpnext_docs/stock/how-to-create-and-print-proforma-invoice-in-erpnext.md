# How to create and print proforma invoice in ERPNext

ERPNext lacks a dedicated "Proforma Invoice" document type. Instead, users can generate one by opening a Quotation or Sales Order, modifying the Print Heading to "Proforma Invoice", then printing it.

## Steps to Print a Proforma Invoice

### 1. Create and Open the Document

- Navigate to your desired Quotation or Sales Order
- Open the specific record you want to output

### 2. Update the Print Heading

- Locate the Printing Settings section within your document
- Access the Print Heading dropdown field
- Select the option to create a new Print Heading
- Enter "Proforma Invoice" as the heading name and save it
- Choose this newly created heading from the dropdown and save your document

### 3. Print or Save as PDF

- Click the Menu button (represented by three dots) or the Print icon at the top
- Confirm your Letterhead selection to include company branding and information
- Select PDF to download to your device, or choose Print for direct hardware output
