# Manufacturer

A manufacturer is an entity that creates or produces items within ERPNext. The manufacturer may differ from the company selling an item under a particular brand—for example, a plastics company might manufacture brushes sold under a different brand name. In ERPNext, manufacturers help identify items using specific part numbers.

To locate the Manufacturer list, navigate to: Home > Stock > Manufacturer

## 1. How to Create a Manufacturer

1. Access the Manufacturer list and select New
2. Input a manufacturer name and optional description
3. Save the record

Following creation, you can establish an **Item Manufacturer** record containing a Manufacturer Part Number for identification purposes.

### 1.1 Additional details

These fields are available for manufacturer records:

- Website
- Country
- Logo

## 2. Features

### 2.1 Address and Contacts

Address and Contact information can be assigned to each manufacturer.
