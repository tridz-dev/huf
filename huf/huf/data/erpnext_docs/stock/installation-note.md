# Installation Note

An Installation Note serves as a documentation tool when products or items are being installed or set up at a customer's location.

## Overview

"An Installation Note can be created when a product/item is being installed or set up at the Customer's place." A practical example would be when selling an Air Conditioner—a service technician accompanying the delivery can document the installation details and date through this note.

To locate Installation Notes, navigate to:
> Home > Stock > Serial No and Batch > Installation Note

## Creating an Installation Note

Installation Notes typically originate from a Delivery Note, though manual creation is also possible. To manually create one, use the 'From Delivery Note' button to retrieve information from a selected delivery record.

**Steps to follow:**
1. Access the Installation Note list and select New
2. Customer, Item, and quantity details automatically populate from the Delivery Note
3. The system automatically records the creation date and time
4. Save and submit the note

Additional installation remarks can be included in the form. For serialized items, corresponding serial numbers should be entered in the Items table.
