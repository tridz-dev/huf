# Automation

Automation in ERPNext serves as a transformative tool for organizations seeking to optimize their operations. As the documentation notes, it proves particularly valuable for "streamlining complex processes like milestone tracking, task assignments, repetitive tasks, and event monitoring."

The platform offers three key automation features:

* [Assignment Rule](/erpnext/user/manual/en/assignment-rule)
* [Auto Repeat](/erpnext/user/manual/en/auto-repeat)
* [Milestone Tracking](/erpnext/user/manual/en/milestone-tracker)

According to the resource, these capabilities deliver dual benefits: they reduce manual workload while simultaneously improving organizational efficiency and output quality.
