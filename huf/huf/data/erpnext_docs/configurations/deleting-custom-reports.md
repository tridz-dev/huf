# Deleting Custom Reports

ERPNext supports multiple [types of reports](/erpnext/making-custom-reports) that users can modify to meet their needs.

When a custom report requires removal, follow these instructions. This process applies exclusively to custom reports, not standard reports.

## Step 1: Go to Report List

Use the Awesome Bar to search for and select "Report List".

![Report Search](/files/customize-deleting-reports-1.png)

## Step 2: Delete the Report from the List

The Report List displays all standard and custom reports in your account. Locate the custom report you wish to remove and click the Delete icon in the Actions Menu.

![Report List](/files/customize-deleting-reports.png)

Alternatively, you can open the specific report and delete it through the File menu.

![Report Delete](/files/customize-deleting-reports-2.png)
