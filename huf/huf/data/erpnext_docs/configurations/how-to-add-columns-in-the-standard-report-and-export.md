# Add columns in Standard Report and Export

In **Standard Reports** of **ERPNext** such as *SOA, Accounts Receivable/Payable etc*, there is functionality to **Add/Remove Columns** from documents for display in the Report. These columns serve as reference points for the current viewing session.

If a user wants to **Export** the report while preserving customizations made during the session, the report must first be saved before exporting. This ensures that column modifications are retained in the exported file.
