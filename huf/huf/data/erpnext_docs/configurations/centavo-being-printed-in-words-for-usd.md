# Print "Centavo" in Words for USD

For currencies not present in the Currency list doctype, follow these steps:

1. Navigate to the Currency list doctype
2. Add the currency
3. Add the exchange rate
4. Enable the currency
5. Add the currency in any transaction as needed

The documentation includes visual examples demonstrating the currency setup process and the resulting print format for displaying currency amounts in words.
