# Procurement Tracker Report

This report displays all transactions pertaining to goods currently undergoing the procurement process.

To access this report, navigate to:

> Home > Buying > Procurement Tracker

The procurement tracker enables users to oversee the acquisition of goods. It furnishes details regarding the requesting party, the warehouse origin, and item quantities. Additionally, it offers a side-by-side comparison of the "estimated cost of the goods at the time of requisition versus actual cost of obtaining them along with the date at which the goods where obtained." This functionality supports review, ordering, delivery, and billing oversight throughout the procurement workflow.
