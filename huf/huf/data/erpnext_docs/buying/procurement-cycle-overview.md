# Procurement Cycle Overview

For a foundational grasp of the procurement workflow in ERPNext, the process encompasses **7 distinct stages**:

1. Material Request
2. Request For Quotation
3. Supplier Quotation
4. Purchase Order
5. Purchase Receipt
6. Purchase Invoice
7. Payment Entry

## Standard Purchase Flow

The typical acquisition workflow begins when users initiate a "Material request in ERPNext depending upon the item to be Purchased."

When multiple vendors are bidding on identical items, a **Request for Quotation (RFQ)** becomes necessary. Suppliers respond with their pricing for the specified quantities through ERPNext or via web portal access.

Once quotation responses arrive, they undergo comparison using the Supplier Quotation feature. Following quote evaluation, a **Purchase Order** is generated against the selected option. Subsequently, the organizational flow determines whether an **Invoice** or **Purchase Receipt** is created first, with "Payment Entry is made" to finalize the transaction.
