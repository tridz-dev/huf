Non-interactive execution:
  -p, --prompt <TEXT>            Prompt text. Appended to stdin input if provided. Forces
                                  non-interactive mode.
                                  Example: gemini -p "summarize README.md"
  -i, --prompt-interactive <TEXT>  Execute prompt and continue in interactive mode.

Output format:
  -o, --output-format <text|json|stream-json>   (default: text)

Session management:
  -r, --resume <latest|INDEX|SESSION_UUID>   Resume a previous session. Use 'latest' for the
                                              most recent, or an index number, or a full UUID.
                                              Examples:
                                                gemini -r "latest"
                                                gemini -r "abc123" "Finish this PR"
  --list-sessions                Display available sessions for the current project.
  --delete-session <INDEX>       Remove a session by index number.

MCP configuration:
  --allowed-mcp-server-names <names...>   Comma-separated list of permitted MCP servers.
  gemini mcp add <name> <command>         Add a stdio-based MCP server.
  gemini mcp list                         View configured MCP servers.
  gemini mcp remove <name>                Remove an MCP server.
